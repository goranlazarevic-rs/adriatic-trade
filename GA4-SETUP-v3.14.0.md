# Google Analytics 4 — setup za Adriatic Trade

1. Kreirati Google Analytics nalog/property za Adriatic Trade.
2. Kreirati Web data stream za `https://adriatictrade.rs`.
3. Measurement ID: `G-WX8JF1GHRT`.
4. ID je upisan u `assets/js/analytics-config.js`.
5. Deploy sajta.
6. Pri prvom testu prihvatiti analitiku i proveriti Realtime/DebugView.
7. Označiti `purchase` kao Key event u GA4.

Preporučeni custom events za kasniji dashboard:
- smart_cart_shown
- smart_cart_added
- smart_cart_purchase
- free_shipping_purchase
